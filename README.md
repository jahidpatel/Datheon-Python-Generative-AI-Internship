# Python + Generative AI & LangChain Internship

A collection of four hands-on projects developed during my one-month internship at **Datheon – AI System and Automation Studio**.

This internship focused on building real-world Generative AI applications using Python, Large Language Models (LLMs), LangChain, Retrieval-Augmented Generation (RAG), vector embeddings, and autonomous AI agents.

## Projects Completed

### Task 1: Structured LLM Prompt Pipeline & JSON Extractor
- Developed an AI-powered document extraction system.
- Extracts structured information from resumes and invoices.
- Converts unstructured PDF content into structured JSON.
- Uses Pydantic for data validation.

### Task 2: RAG Document Question Answering
- Built a Retrieval-Augmented Generation (RAG) application.
- Loads and processes PDF and text documents.
- Generates vector embeddings and performs semantic search.
- Answers user questions using retrieved document context.

### Task 3: Multi-Tool Autonomous AI Agent
- Developed an autonomous AI agent using Python and LangChain.
- Integrated multiple tools to perform different tasks.
- Enables the agent to select and execute appropriate tools based on user queries.

### Task 4: Interactive AI Chatbot
- Developed an interactive AI chatbot with a Streamlit interface.
- Supports document uploads and document-based question answering.
- Implements separate chat sessions with independent conversation history.
- Provides context-aware answers and handles questions outside the uploaded documents appropriately.
